# 💖 Forever & Always • Romantic Couple Portrait & Living Hearts Animation

An interactive web and Python Turtle experience that transforms a personal couple photograph into an animated digital art reveal and living romantic environment.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/DevNs-cmd/romantic-couple-portrait)

---

## ✨ Features

- **Act 1: Hand-Drawn Silhouette Sketching**
  - Preliminary vector lines sketch out the couple's silhouettes, hair curls, flowing waves, and expressive facial contours.
- **Act 2: Magic Watercolor & Photographic Color Bloom**
  - A glowing magic paintbrush spirals outward from their radiant smiles, blooming the **100% crystal-clear, photorealistic portrait** with **zero marks, zero lines on faces**.
- **Act 3: Living Romantic Environment (Continuous 60 FPS)**
  - **Pulsing Twin Hearts**: Realistic heartbeat pulse (`lub-DUB`) above the couple.
  - **40+ Floating Romantic Hearts**: Continuous sinusoidal drift of hearts in ruby, magenta, rose, and gold.
  - **Twinkling Golden Fairy Lights & Fireflies**: Soft celestial ambiance.
  - **Interactive Touch & Click Bursts**: Tapping anywhere spawns bursts of floating love hearts!
  - **Romantic Ambient Music Synthesizer**: Built-in soothing harp/celesta ambient chords powered by the Web Audio API.

## 🚀 Quick Start

### Local Preview
Open `index.html` in any modern web browser, or run a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```

### Python Turtle Script
To run the original desktop turtle animation:
```bash
python turtle_portrait.py
```

## 🛠️ Tech Stack
- **Frontend:** HTML5, Modern Canvas API, Web Audio API, Vanilla CSS3 (Glassmorphism & Keyframe Animations)
- **Computer Vision:** OpenCV (Bilateral Filtering, Canny Edge Detection, Haar Cascades)
- **Deployment:** Vercel & GitHub Pages
